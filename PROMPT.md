# Сценарий для агента

Я хочу проверить и оптимизировать свой Windows-ПК с помощью этого репозитория.

Моя цель: <долгая загрузка / тормоза / нехватка ОЗУ / мало места / общий анализ>.
ПК: <этот компьютер / имя конкретного удалённого компьютера>.
Что должно продолжить работать: <игры, печать, VPN, Bluetooth, синхронизация и т. п.>.

Прочитай AGENTS.md, README.md и docs/design.md. Используй готовые tools/, не заменяй
их случайными твиками из интернета. Работай по этапам:

1. Уточни незаполненные сведения, которые нужны для моей цели. Если работаешь на этом ПК,
   используй локальный сбор. Для другого ПК следуй docs/connection.md. Не настраивай сеть сам.
2. Запусти tools/Collect-Snapshot.ps1, сохрани путь отчёта. Прочитай секции, ошибки и лимиты.
   Запусти tools/Analyze-Snapshot.ps1. Повторяемая CPU-нагрузка важнее одного короткого снимка.
3. Объясни, что замедляет компьютер: ОЗУ и её доступность, процессы и потоки CPU, автозапуск,
   работающие службы, состояние устройств/драйверов, свободное место. Отдели измерения от гипотез.
   Число потоков не является мерой вредоносности или полезности процесса.
4. Если видишь подозрительное ПО, проверь путь, издателя, подпись и хеш через Inspect-File.ps1.
   Не запускай его. Не загружай файл/хеш наружу без разрешения. Отсутствие подписи не приговор.
5. Подготовь короткую таблицу: объект, факты, предлагаемое действие, ожидаемый эффект, риск,
   способ отката. Расставь приоритеты под мою цель. Не обещай проценты ускорения без измерений.
6. Согласуй конкретные изменения и предпочтения, если они ещё не согласованы. Не спрашивай
   разрешение на каждый диагностический шаг. Начни с обратимых изменений автозапуска HKCU Run,
   используя Set-StartupEntry.ps1 с предпросмотром; сохрани напечатанный путь резервной копии.
   Неподдерживаемые изменения предложи отдельно; не обходи ограничения инструмента.
7. После каждого изменения проверь фактическое состояние. После входа/перезагрузки, если я её
   разрешил, повтори тот же замер при сопоставимой нагрузке. Проверь мои основные приложения.
8. Дай итог: что измерено, что изменено, где отчёты и резервные копии, точная команда отката,
   что осталось непроверенным. Не называй найденный TEMP гарантированно безопасным к удалению.

Не выполняй очистку ОЗУ, массовое отключение служб, "чистку реестра", отключение защиты,
обновлений, файла подкачки или установку сторонних драйвер-паков ради красивого отчёта.
