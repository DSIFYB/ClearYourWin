# Проверка первой версии

## Дополнение: очистка и обслуживание v0.2

25 октября 2026 года: **30 проверок** в PowerShell 7.6.5 и Windows PowerShell 5.1.
В 5.1 использован RemoteSigned только для дочернего тестового процесса, без постоянного изменения
политик. Проверены также компиляция C# штатным Add-Type и фактическое удаление через Win32 handle.

- Применение очистки проверено только на специально созданных файлах внутри tests/.
- Проверены preview/WhatIf, журнал до удаления, пропуск занятых/изменённых файлов, повторный запуск,
  замена файла с теми же размером/датами, подмена родительского каталога junction, лимиты и отказ
  создания журнала. Контрольный файл за пределами выбранного тестового TEMP сохранён.
- Проверены сроки планов, ПК/SID, недопустимые корни/команды, отсутствие ResetBase и принудительного
  Defrag, записи успеха/ошибки обслуживания и обработка rebootRequired без перезагрузки.
- Проверены signed delta сравнения, несовпадение цели/дат и сохранение null для отсутствующих метрик.
- Реальные команды DISM/SFC/Optimize-Volume/DNS в тестах подменены; их запуск на реальной системе
  и эффект требуют приёмки в VM. Настройки ПК и настоящий TEMP не изменялись.
- Для native handle-проверок в среде разработки нужен запуск вне песочницы: ограниченная среда
  запрещает открытие дескрипторов каталогов-предков. Инструмент при этом отказывает, а не переходит
  к небезопасному удалению по пути.

## Исходная диагностическая версия v0.1

Проверено 25 октября 2026 года на Windows 11, PowerShell 7.6.5:

- `pwsh -NoProfile -File tests/Run-Tests.ps1`: 15 проверок пройдены.
- Полный локальный сбор с `-SampleSeconds 1 -IncludeThreads -MaxScanEntries 1000 -ScanSeconds 2`:
  JSON сформирован, анализатор прочитал его. Получены ОС/ОЗУ, 253 процесса, 128 потоков десяти
  выбранных процессов, 44 объекта автозапуска, 289 служб, 155 PnP-драйверов, 428 системных
  драйверов, 154 устройства, диски, приложения и состояние Defender. Числа зависят от момента.
- Ограниченный обход TEMP честно отмечен `partial` при лимите/недоступных ветках.
- Проверен отказ доступа в песочнице: остальные секции собираются, анализ показывает пробелы.
- Inspect-File успешно получил SHA-256 и NotSigned для одного из скриптов проекта.
- Все исходники прошли синтаксический разбор встроенным Windows PowerShell 5.1.

Для CIM-проверок потребовалось чтение вне песочницы среды разработки; изменения системных
настроек и запуск оптимизации на рабочем ПК не выполнялись. Снимки находятся в локальном
`reports/`, исключённом из Git. Они содержат личные данные, поэтому не входят в примеры.

Не проверено на реальном целевом окружении:

- Применение и восстановление настоящей записи автозапуска — нужен отдельный тестовый профиль/VM.
  Автотесты проверяют журнал и ветку WhatIf с подменой данных, не запись в настоящий реестр.
- Сбор через PSSession — нужна разрешённая тестовая машина с настроенным remoting.
- Полный сбор реальных системных секций на PowerShell 5.1: он остаётся отдельной приёмкой.
  Автономные тесты на 5.1 теперь пройдены, как указано выше; постоянные политики не менялись.
- Реальный выигрыш в загрузке/CPU/памяти: никакие настройки ПК не менялись, сравнения до/после нет.
