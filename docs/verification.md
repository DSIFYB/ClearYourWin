# Проверка первой версии

Проверено 25 октября 2026 года на Windows 11, PowerShell 7.6.5:

- `pwsh -NoProfile -File tests/Run-Tests.ps1`: 15 проверок пройдены.
- Полный локальный сбор с `-SampleSeconds 1 -IncludeThreads -MaxScanEntries 1000 -ScanSeconds 2`:
  JSON сформирован, анализатор прочитал его. Получены ОС/ОЗУ, 253 процесса, 128 потоков десяти
  выбранных процессов, 44 объекта автозапуска, 289 служб, 155 PnP-драйверов, 428 системных
  драйверов, 154 устройства, диски, приложения и состояние Defender. Числа зависят от момента.
- Ограниченный обход TEMP честно отмечен `partial` при лимите/недоступных ветках.
- Проверен отказ доступа в песочнице: остальные секции собираются, анализ показывает пробелы.
- Inspect-File успешно получил SHA-256 и NotSigned для одного из скриптов проекта.
- Все исходники прошли синтаксический разбор встроенным Windows PowerShell 5.1.

Для CIM-проверок потребовалось чтение вне песочницы среды разработки; изменения системных
настроек и запуск оптимизации на рабочем ПК не выполнялись. Снимки находятся в локальном
`reports/`, исключённом из Git. Они содержат личные данные, поэтому не входят в примеры.

Не проверено на реальном целевом окружении:

- Применение и восстановление настоящей записи автозапуска — нужен отдельный тестовый профиль/VM.
  Автотесты проверяют журнал и ветку WhatIf с подменой данных, не запись в настоящий реестр.
- Сбор через PSSession — нужна разрешённая тестовая машина с настроенным remoting.
- Полное выполнение на PowerShell 5.1: локальная политика запуска его файлов отклонила команду;
  постоянные политики не менялись. Совместимость синтаксиса проверена, runtime-приёмка остаётся.
- Реальный выигрыш в загрузке/CPU/памяти: никакие настройки ПК не менялись, сравнения до/после нет.
