# План развития

## 0.1 — основа (реализовано)

- [x] README, PROMPT, AGENTS, архитектура и сценарий подключения.
- [x] Сборщик JSON с частичными ошибками, интервальным CPU, памятью и перечнем потоков.
- [x] Автозапуск, службы, драйверы, устройства, диски и приложения.
- [x] Ограниченный обход TEMP/явно указанных каталогов; никаких удалений.
- [x] Детерминированный анализ и точечная подпись/хеш файла.
- [x] Предпросмотр, журнал и восстановление отдельной записи HKCU Run.
- [x] Скрипт сбора через существующую PSSession.
- [x] Автономные проверки анализа, обхода, JSON и синтаксиса.

Критерий: инструменты выполняются без сторонних пакетов; отказы доступа видны; анализ не меняет
систему; тесты не трогают реальный автозапуск. Подключение к чужому ПК и запись HKCU Run требуют
отдельной ручной приёмки на тестовой Windows-VM; тесты на рабочем ПК их не подтверждают.

## 0.2 — измеряемая оптимизация

- [ ] Сравнение двух снимков, несколько CPU-замеров и время загрузки при сопоставимых условиях.
- [ ] StartupApproved, MSIX StartupTask и задачи: точное состояние и поддерживаемое отключение/откат.
- [ ] Формат плана действий с целевым ПК/SID, сроком актуальности, предпросмотром и проверкой drift.
- [ ] Очистка только согласованного списка TEMP: повторная проверка, reparse/TOCTOU-защита,
      лимит байт, пропуск занятых файлов, журнал. Не обещать откат окончательно удалённых файлов.
- [ ] Штатная очистка компонентов Windows как отдельный сценарий со своими ограничениями.

Критерий: приёмочные тесты в VM, прерывание и повторный запуск, проверка потери связи и отката;
измерения до/после и подтверждение работоспособности пользовательских задач.

## 0.3 — приложения и расследование

- [ ] MSIX/portable-инвентаризация, сопоставление процессов/автозапуска/служб/издателей.
- [ ] Согласованная точечная проверка Defender с корректной обработкой обнаружения/карантина.
- [ ] План удаления пользовательских приложений через штатные установщики, без выполнения
      произвольных строк из отчёта. Учитывать, что удаление не всегда обратимо.
- [ ] База рекомендаций с источниками, версиями ОС, зависимостями и перечнем защищённых компонентов.
